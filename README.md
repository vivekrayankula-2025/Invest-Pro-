InvestPro - Simplified Version

Files:
1. index.html  - All website pages combined into one HTML file.
2. style.css   - All styling in one CSS file.
3. images/     - Local SVG illustrations (teal theme) and the finance background.
4. Real photos - Loaded from Unsplash (free under the Unsplash License).
                 An internet connection is needed to see them.

No JavaScript is used.

Open index.html in Chrome/Edge.
Use the navigation links to move between sections.

The forms are demo forms only. They do not create real accounts,
perform real login, or process real financial transactions.
